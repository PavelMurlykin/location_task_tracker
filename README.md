# Задачи рядом

Android-приложение на Kotlin для задач с напоминаниями по местоположению.

## Возможности MVP

- локальный список активных и выполненных задач;
- поиск по задачам и адресам, фильтры и сортировка по сроку, расстоянию и приоритету;
- название, описание и срок задачи;
- приоритет задачи и быстрые свайп-действия с возможностью отмены;
- категории, теги и чек-листы с отображением прогресса;
- ежедневные, еженедельные и ежемесячные повторяющиеся задачи;
- архив выполненных задач и восстановление из него;
- дублирование существующей задачи из редактора;
- привязка координат, адреса и радиуса геозоны;
- выбор точки на Яндекс Карте или ручной ввод координат;
- уведомления при входе и выходе из геозоны с расписанием и тихими часами;
- обычные напоминания по сроку для задач без геозоны;
- выполнение задачи непосредственно из уведомления;
- отложенные уведомления на 15 минут, час или до следующего визита;
- сохранённые места и история недавно использованных адресов;
- выбор адреса из нескольких результатов поиска;
- быстрое создание задачи, голосовой ввод и приём текста через «Поделиться»;
- восстановление геозон после перезагрузки устройства и обновления приложения;
- отображение состояния регистрации каждой геозоны и автоматические повторные попытки;
- безопасное распределение системного лимита в 100 активных геозон;
- диагностика разрешений, энергосбережения и журнал последних событий геозон;
- русская и английская локализации интерфейса;
- настройка интервала между повторными уведомлениями.

## Карта и планирование дел

- общая карта всех активных задач с объединением близких меток и счётчиком задач в одном месте;
- экран «Рядом» с сортировкой по расстоянию от текущей позиции;
- локальная оптимизация порядка нескольких остановок и подсказки о задачах по пути;
- быстрое создание задачи долгим нажатием на общую карту.

Маршрут строится локально как ориентировочная линия между остановками и не отправляет список дел
в сторонний сервис маршрутизации.

## Защита данных

- экспорт и восстановление задач, мест и настроек напоминаний через локальный файл `.ltbackup`;
- обязательное шифрование резервной копии AES-256-GCM с ключом, полученным из пароля через PBKDF2;
- проверка целостности файла до изменения базы и восстановление Room-данных одной транзакцией;
- опциональная блокировка входа системным PIN-кодом, паролем или биометрией Android;
- скрытие текста напоминаний на заблокированном экране и запрет снимков экрана при включённой блокировке;
- отключённый автоматический облачный backup Android.

Облачной синхронизации, аккаунтов и серверной части в приложении нет. Пароль резервной копии
не сохраняется: при его утрате расшифровать файл невозможно.

## Запуск

1. Установите Android Studio с Android SDK 36 и JDK 17.
2. Создайте файл `local.properties` в корне проекта:

   ```properties
   sdk.dir=C\:\\Users\\USER\\AppData\\Local\\Android\\Sdk
   MAPKIT_API_KEY=ваш_ключ_Yandex_MapKit
   ```

   `MAPKIT_API_KEY` необязателен: без него координаты можно указать вручную или
   получить с устройства. Получите ключ MapKit Mobile SDK в кабинете разработчика
   Яндекса и выберите бесплатный тариф. Активация нового ключа может занять около
   15 минут.

   Проект использует облегчённую библиотеку MapKit Lite. Тариф назначается ключу
   в кабинете разработчика, а не Gradle-зависимостью. На бесплатном тарифе
   действует лимит 1 000 уникальных пользователей карты в сутки (DAU) и
   [условия бесплатного использования](https://yandex.ru/dev/commercial/doc/ru/concepts/mapkit).

3. Откройте проект в Android Studio и запустите конфигурацию `app`.

Или соберите из терминала:

```shell
./gradlew assembleDebug
./gradlew test
```

## Важные разрешения

Геонапоминания требуют точного местоположения и разрешения использовать
местоположение в фоне. На Android 13 и новее уведомления также имеют отдельное
разрешение. Обычные задачи работают и без этих разрешений.

Перед публикацией необходимо заполнить раздел Data safety, добавить политику
конфиденциальности и пройти декларацию фонового доступа к местоположению в
Google Play Console.

## Подготовка к публикации

- при первом запуске онбординг объясняет геозоны и последовательно запрашивает точную геопозицию, фоновый доступ и уведомления;
- поддерживаются светлая, тёмная и системная темы;
- необязательные Sentry и PostHog запускаются только после явного согласия пользователя;
- локально считаются успешность регистрации геозон, доля доставленных напоминаний, выполнение из уведомления и D1/D7 retention;
- GitHub Actions выполняет `assembleDebug`, unit-тесты и `lintDebug`, а затем сохраняет APK и отчёты;
- ручные проверки доступности и публикации описаны в `docs/ACCESSIBILITY_CHECKLIST.md` и `docs/RELEASE_CHECKLIST.md`.

Для диагностики можно добавить в `local.properties` или CI secrets:

```properties
SENTRY_DSN=https://examplePublicKey@o0.ingest.sentry.io/0
POSTHOG_API_KEY=phc_example
POSTHOG_HOST=https://eu.i.posthog.com
```

Без этих параметров приложение работает полностью локально. Даже с параметрами
SDK не инициализируются до согласия пользователя; названия задач, адреса,
координаты и заметки в события не включаются.
